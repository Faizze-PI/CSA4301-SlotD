# CSA4301 - Internet Programming Lab Programs

This folder contains all 46 lab experiments for CSA4301 (Internet Programming Lab), SIMATS Engineering.

## How to Run

### Option 1: Start the local server
From this folder (`Lab/Programs`), run:
```bash
npm start
```
Then open `http://localhost:3000` to open the lab portal.

### Option 2: Open directly in a browser
You can also open `index.html` inside any experiment folder directly in any modern browser (Chrome, Edge, Firefox).

## Folder Structure

Each experiment is self-contained in its own folder:
- `index.html`: Web page layout and forms
- `styles.css`: CSS styling
- `script.js`: Interactive logic and calculations
- `README.md`: Lab write-up with aim, algorithm, and viva questions

Shared files:
- `index.html`: Portal page linking to all experiments
- `shared/css/theme.css`: Common layout styling
- `shared/js/db.js`: Local storage helper for data persistence
