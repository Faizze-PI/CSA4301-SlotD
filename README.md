# CSA4301 - Internet Programming Lab

Lab experiments for CSA4301 (Slot D), Department of Computer Science and Engineering, SIMATS Engineering.

## Repository Contents

- [Programs](./Lab/Programs) - Source code, HTML, CSS, JavaScript, and lab manuals for all experiments.
- [Outputs](./Lab/outputs) - Screenshots of every completed program.

## Running the Programs

### Run locally with Node.js
```bash
cd Lab/Programs
npm start
```
Then open `http://localhost:3000` to view the lab portal.

### Or open directly in a browser
You can also open `index.html` from any experiment folder directly in Chrome, Edge, or Firefox.
